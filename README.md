# 📌 About The Project

This project is a **beautiful and interactive web application** built to celebrate birthdays with style and joy.

It transforms a simple birthday greeting into a **fully animated celebration experience** featuring confetti bursts, floating balloons, fireworks, music, and personalized messages.

The goal is to create a **fun, memorable, and visually engaging experience** that anyone can use to surprise friends, family, or loved ones.

✨ *Because every birthday deserves a little magic.*

---

# 🎉 Features

| Feature                          | Description                                    |
| -------------------------------- | ---------------------------------------------- |
| 🎊 **Confetti Explosion**        | Colorful confetti bursts across the screen     |
| 🎂 **Interactive Birthday Cake** | Light candles and blow them out                |
| 🎈 **Floating Balloons**         | Balloons float smoothly with physics animation |
| 🎇 **Fireworks Animation**       | Fireworks explode during celebration           |
| 🎵 **Birthday Music**            | Background music enhances the experience       |
| 💌 **Custom Birthday Messages**  | Personalize wishes for the celebrant           |
| ⏳ **Birthday Countdown Timer**   | Animated countdown to the big day              |
| 🌈 **Multiple Color Themes**     | Switch between vibrant celebration themes      |
| 📱 **Responsive Design**         | Works perfectly on mobile, tablet, and desktop |
| ⚡ **Fast & Smooth Animations**   | Optimized for performance                      |

# ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/SmithC05/birthday.git
cd birthday
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Start Development Server

```bash
npm run dev
```

### 4️⃣ Open in Browser

```
http://localhost:5173
```

### 5️⃣ Build for Production

```bash
npm run build
```
